### What I have shipped

**[SafeX Intern Management Portal](https://github.com/abisha-faisal/safex-intern-portal)**
Full-stack internal tool for a company's intern program, built solo from spec to production.
- Next.js 14 (App Router) and TypeScript on the frontend, Supabase (Postgres, Auth, Row Level Security) on the backend
- Every permission is enforced at the database layer with RLS policies and triggers, not just hidden in the UI
- Feedback anonymity is architectural: the schema has no author column at all, so it cannot be traced back even by an admin
- Deployed on Vercel with a full CI workflow: pull request, preview deploy, merge, production
